* \# IIIT Hyderabad Internship - Computer Vision Pipeline
* 
* \## Week 1
* \- Task 1: Downloaded YouTube video using yt-dlp, extracted 1800 frames using ffmpeg
* \- Task 2: Reconstructed video from frames at 30fps
* \- Task 3: Clipped audio using Audacity, merged with video using ffmpeg
* 
* \## Week 2
* \- Task 1: Python virtual environment setup using venv
* \- Task 2: Installed Ultralytics YOLOv8 package
* \- Task 3: Ran object detection using pretrained YOLOv8 model
* 
* \## Week 3
* \- Task 1: Analyzed model performance metrics (mAP, precision, recall)
* \- Task 2: Ran semantic segmentation, stacked raw+detected+segmented videos
* 
* \## Week 4
* \- Task 1: Explored YOLO dataset YAML configs and bounding box label formats
* \- Task 2: Created custom dataset (8175 frames), annotated 174 images using Label Studio
* 
* \## Week 5 - Custom Model Training
* \- Task 1: Completed annotation, generated yaml, train.txt, val.txt
* \- Task 2: Resized images to 384px using ffmpeg
* \- Task 3: Fine-tuned YOLOv8n for 50 epochs — Precision: 74.5%, mAP50: 55.9%
* \- Task 4: Ran detection on 199 test images using custom weights
* \- Task 5: Created final stacked video (raw + detected) with music
* 
* \## Results
* | Metric | Score |
* |---|---|
* | Precision | 74.5% |
* | Recall | 46.7% |
* | mAP50 | 55.9% |
* | Training time | 17 mins (CPU) |
